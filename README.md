# SATHY

SATHY is a simple social platform for discovering friends, communities, and
activities based on shared interests and location.

This repository currently contains the **project foundation** only — no
features (auth, database, posts, communities, activities, etc.) have been
built yet. They will be added one piece at a time, following
[`docs/ROADMAP.md`](./docs/ROADMAP.md).

## Stack

- Next.js (App Router)
- JavaScript (no TypeScript)
- Tailwind CSS
- ESLint

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
